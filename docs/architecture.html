Data flow

Request path

filter change to rendered view
  1. User changes a filter (period, warehouse, category, status) in FilterBar.
  2. useFilters updates shared refs; views watching them reload.
  3. getCurrentFilters() maps the state to params (period becomes month); api.js omits values equal to all.
  4. FastAPI filters the in-memory lists and validates output with Pydantic.
  5. The view stores raw data in refs; computed properties derive chart and table data.

Notes and gaps found

  • Missing routes: api.js calls /api/tasks (list, create, delete, toggle) and /api/purchase-orders, but server/main.py defines neither. Those calls will return 404.
  • Unrouted view: views/Backlog.vue exists but has no entry in the router in main.js.
  • Hard-coded API URL: http://localhost:8001/api is set in api.js; there is no environment config or Vite proxy.
  • Volatile state: there is no database, so any write would exist only until the server restarts.
  • CORS: allow_origins=["*"] is fine for a local demo, not for production.
